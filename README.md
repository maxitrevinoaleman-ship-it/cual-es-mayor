# ¿Cuál es mayor?

Un minijuego para practicar el sentido numérico (útil para la discalculia). Toca el lado más grande antes de que se acabe el tiempo.

**Modos**
- **Puntos:** compara cantidades de puntos sin contar.
- **Números:** cifras que se parecen cada vez más.
- **Parecidos:** números que se confunden fácil, como 17 y 71 o 6 y 9.

## Jugar

Abre el link de GitHub Pages del repo en tu celular y agrégalo a tu pantalla de inicio:

- **Android (Chrome):** ⋮ → *Agregar a la pantalla principal*.
- **iPhone (Safari):** Compartir ⬆️ → *Agregar a inicio*.

Es una sola página (`index.html`), sin instalaciones ni cuentas.
